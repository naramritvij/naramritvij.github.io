AI Flashcard Generator

A Streamlit NLP pipeline that accepts arbitrary study text, segments it with spaCy, uses a fine-tuned T5 model to generate questions from source sentences, and exports the resulting flashcards as CSV.

PythonStreamlitspaCyT5Hugging Face
Repository ↗

01 / overview

Turn raw study material into structured question-answer pairs.

The application combines deterministic NLP preprocessing with generative question creation. spaCy defines sentence boundaries, T5 generates a question from the selected source text, and the original sentence remains the answer so each card stays grounded in the input.

01Text-to-flashcards

The pipeline starts from arbitrary study text rather than a fixed question bank.

02Grounded answers

The source sentence is retained as the answer instead of asking the model to invent both sides.

03Portable output

Generated flashcards can be downloaded as CSV for reuse.

02 / architecture

Deterministic preprocessing before generative question creation.

The model is used for the task it is best at—question generation—while segmentation and answer grounding remain deterministic.

system_viewarchitecture / data flow

The answer stays tied to the original sentence, which makes the generated cards easier to trace back to the study material.

03 / flow

Generation pipeline

Each stage has a narrow responsibility, which keeps the application easy to inspect and extend.

01Paste text

User provides notes, a paragraph, or study material.

02Segment

spaCy splits the text into candidate source sentences.

03Generate

Fine-tuned T5 produces a question for a source sentence.

04Pair

Generated question is matched with the original source sentence as answer.

05Export

Pandas assembles the flashcards for CSV download.

04 / output model

05 / decisions

Key engineering decisions

  • Ground answers in source text — the model generates only the question, reducing unsupported answer generation.
  • Use spaCy for structure — sentence boundaries are handled by a dedicated NLP library instead of relying on generation.
  • Streamlit for iteration — a lightweight interface makes the NLP pipeline directly usable without building a separate frontend.
  • CSV as an interoperability layer — generated study material can move into other tools instead of being trapped in the app.
