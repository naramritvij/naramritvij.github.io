NOra University Chatbot

A university question-answering prototype that ingests academic PDFs, builds a FAISS retrieval index, retrieves relevant course context, and serves answers through Streamlit with optional local FLAN-T5 generation.

PythonFAISSStreamlitPDF retrievalOptional FLAN-T5
Repository ↗

01 / overview

Answer university questions from a bounded document collection.

Rather than treating a language model as a source of truth, NOra starts with university documents. The retrieval layer finds relevant PDF content first, then the application can either summarize retrieved material directly or pass it through a small local generation model.

01Document-grounded

Academic PDFs are the retrieval source for university questions.

02Vector retrieval

FAISS provides fast similarity search over indexed document content.

03Local generation option

FLAN-T5-small can be used for generation, with extractive behavior available as a simpler fallback.

02 / architecture

Retrieval first, generation second.

The architecture separates document ingestion and indexing from the runtime question-answer path.

system_viewarchitecture / data flow

The vector index is prepared from a bounded university corpus. At runtime, the model sees retrieved context instead of answering an unconstrained question from general memory.

03 / flow

Question-answering path

The user-facing path is short because document preparation happens ahead of time.

01Prepare corpus

Academic PDFs are parsed and indexed into the FAISS retrieval store.

02Ask question

The user enters a university-related question in Streamlit.

03Retrieve context

Similarity search selects relevant document content.

04Compose answer

Use extractive summary or optional local FLAN-T5 generation.

05Present

Streamlit returns an answer grounded in the indexed documents.

04 / decisions

Key engineering decisions

  • Bounded document corpus — the application is aimed at university information rather than open-domain chat.
  • Retrieval before generation — FAISS narrows the context before any optional local language-model step.
  • Local model option — FLAN-T5-small allows experimentation without depending on a hosted generation API.
  • Streamlit interface — keeps the prototype focused on retrieval quality and question-answer flow.
