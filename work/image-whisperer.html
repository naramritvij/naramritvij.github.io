Image Whisperer

A browser-native image recognition app that loads MobileNet V2 with TensorFlow.js, classifies a user-selected image entirely on-device, and returns the top three predictions without uploading the image to a server.

React 19TypeScriptTensorFlow.jsMobileNet V2No backend
Live demo ↗Repository ↗

01 / overview

Put inference where the image already is: the browser.

The main architectural decision is privacy and simplicity. The model and inference runtime execute in the client, so image data never needs an application server or external AI API.

01On-device inference

TensorFlow.js runs MobileNet V2 directly in the browser.

02Top 3 predictions

The interface returns ranked labels with confidence percentages.

03Zero AI backend

No server and no model API key are required for classification.

02 / architecture

A complete inference pipeline inside the client.

After the application loads the model, every classification step stays inside the user’s browser.

system_viewarchitecture / data flow

There is no application-server hop in the inference path. The browser owns model loading, image tensor preparation, prediction, and presentation.

03 / flow

Image-to-prediction flow

The interaction remains simple because model complexity is hidden behind one upload action.

01Select image

User drags or chooses a supported image file.

02Preview

React displays the image and prepares the inference state.

03Load / reuse model

TensorFlow.js makes MobileNet V2 available in the browser.

04Classify

The image is processed locally through the pretrained network.

05Rank results

Top three classes and confidence values are shown in the interface.

05 / decisions

Key engineering decisions

  • Client-side inference - keeps images local and removes server and API-key dependencies.
  • Pretrained MobileNet V2 - provides practical general-image recognition without training a model from scratch.
  • Typed React component architecture - TypeScript keeps UI state and prediction data easier to reason about as the interface evolves.
  • Deployment as a static web experience - the application can be hosted like a normal frontend because there is no inference backend.
